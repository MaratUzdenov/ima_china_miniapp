# Китай Сервисы — Mini App для админов (MVP-4)

Telegram Mini App поверх Google Таблицы заказов. Данные берёт из Apps Script API (`Api.gs` в проекте таблицы),
таблица — единственный источник правды. Ничего не хранит у себя.

## Что уже есть
- Экран «Заказы»: вкладки «В работе / Доставлены / Все», поиск по товару, клиенту, ID и треку,
  товары одного заказа — одной карточкой, полоска статуса по цепочке, значки «нет веса», «нет ссылки», «просрочен», долг.
- Три состояния: загрузка (скелетон), пусто, ошибка с кнопкой «Повторить».
- Цвета только из темы Telegram (светлая/тёмная — сами).
- Демо-режим: пока не задан адрес API или приложение открыто в обычном браузере — показываются демо-данные с плашкой.

## Как устроено
- React + Vite + TypeScript, `@telegram-apps/sdk` (тема, initData, кнопка «Назад»).
- Запрос: `POST <адрес>/exec?api=1`, `Content-Type: text/plain`, тело `{ method, params, initData }`.
  Подпись initData проверяет бэкенд; пускает только админов из «Настроек».
- Адрес API — переменная `VITE_API_URL` в файле `.env`. Это не секрет.

## Разработка
```
npm install
npm run dev       # http://localhost:5173/ima_china_miniapp/ — демо-данные
npm run build     # сборка в dist/
```

## Если что-то сломалось
| Симптом | Что делать |
|---|---|
| Плашка «Демо-данные» в Telegram | Не задан `VITE_API_URL` — пересобрать с адресом `/exec` |
| «Таблица ответила не так, как ожидалось» | В Apps Script не сделана «Новая версия» развёртывания |
| «Mini App пока только для админов. Ваш Telegram ID: …» | Этого ID нет в Настройках → «Админы» |
| «Сессия устарела» | Закрыть и открыть Mini App заново |
| Белый экран | Проверить, что Pages публикует ветку `gh-pages`, и что `base` в `vite.config.ts` = имени репозитория |
